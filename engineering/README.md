# engineering

Working area for RFC drafts, design notes, and meeting records — the
unstructured, in-flight material that has not yet been formalized into an
NPS, ADR, or NPC document (see NPC-001 §4 for the document classes).

Currently empty. Notes here are explicitly non-normative; anything that
graduates into a decision MUST follow the change process (NPC-001 §6) and
be reflected in `SPECIFICATION_INDEX.md`, `REPOSITORY_STATE.md`, and
`CHANGE_REQUEST_LOG.md` in the same commit.
